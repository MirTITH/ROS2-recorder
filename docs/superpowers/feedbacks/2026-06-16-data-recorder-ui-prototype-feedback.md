## 2. UI 布局调整

2.0. 整体：
2.0.1 降低面板标题栏的高度到 20 像素（1 倍 DPI 缩放下）
2.0.2 面板之间的分割线改为 1 像素的灰色线，当鼠标悬停在分割线上时，分割线变为蓝色、变粗，并且鼠标指针变为调整大小的双向箭头。

2.1. 删除话题列表的面板，把话题列表的内容放到时间轴中。

2.2. 相机预览面板：
    2.2.1. 相机预览面板需要可调整高度
    2.2.2. 相机画面尺寸需要随面板尺寸调整，必须保证所有相机画面都能显示在面板中，且不被裁剪。（不能使用滚动条）
    2.2.3. 用户可以通过拖动相机画面来调整顺序。
    2.2.4. 相机画面不能被任何元素遮挡，当前的 UI 设计中，底部的 video 和帧率会遮挡相机画面。可以考虑删除 video 和帧率，帧率信息可以在时间轴里获得。在相机画面标题栏上显示分辨率，右对齐。
    2.2.5. 减少相机画面之间的间距。降低相机画面标题栏的高度，尽可能为相机画面提供更多的显示空间。
    2.2.6. 在没有相机画面需要预览时，隐藏相机预览面板

2.3. 采集记录面板：
    2.3.1. 条目的标题应该为文件夹名称（见 3. 输出目录结构，如 2026-05-31_07-46-20, 用户自己改的名称）。如果标题太长就截断，鼠标悬停时显示完整名称。
    2.3.2. 删除记录的磁盘占用，把磁盘占用放到鼠标悬停时显示的提示信息里。
    2.3.3. 时长改成 24s, 154m35s 这样的格式，放在条目的第二行，左对齐。鼠标悬停时显示完整的时长信息（比如 时长：00:24:21.123）
    2.3.4. 在采集面板的条目中添加采集记录的标签，放到条目的第二行，右对齐。样式为：无边框圆角矩形背景，背景颜色根据标签不同而不同，标签文字为黑色或白色，确保有足够的对比度以便阅读。标签大小尽可能小，确保能塞入条目的第二行。如果标签过长，则隐藏标签文字，只显示背景颜色对应的小圆点。
    2.3.5. 条目之间不要添加间隙，仅使用水平分隔线分隔。删除条目左右两侧的边框。

2.4. 录制按钮：在整个界面按空格键相当于点击了录制按钮。

2.5. 记录标签面板：标签的样式与 2.3.4 中描述的样式相同。

2.6. 时间轴面板：
    2.6.1. 样式模仿 `src/data_recorder/docs/reference/Premiere Pro Timeline.png`。Premiere Pro 的这个面板中有很多元素和功能，我们的程序不需要这么多元素。时间轴面板总体上分为两部分：左侧是信息面板，右侧是曲线图。信息面板中显示了每个 topic 的名称和频率，对于相机 topic，还有眼睛图标用于显示/隐藏相机画面。曲线图中显示了每个 topic 的曲线（如果不能画出曲线，则留空）。
    2.6.2. 当前曲线图的边距过大，需要删除边距。
    2.6.3. 在时间轴上拖动鼠标时，播放头应该跟随鼠标移动。当前是每次鼠标松开时才更新播放头位置，这样会导致播放头跟不上鼠标移动，体验很差。
    2.6.4. 在信息面板处滚动鼠标，应该上下滚动轨道，在曲线图处滚动鼠标，应该放大缩小时间轴。
    2.6.5. 现在的 UI example 不合理，/tf 和 /tf_static 应该无法画出曲线才对，/joint_states 才能画出曲线，而且是多条曲线。

2.7. 事件标记的按钮样式不好。应该通过样式来暗示是时间点还是区间。对于时间点，用户点击时，如果播放头处有该事件标记，则删除该事件标记；如果播放头处没有该事件标记，则添加一个新的事件标记。对于区间，用户点击时，如果播放头处在该区间内，则删除该区间；如果播放头处不在该区间内，将区间起点设置在播放头位置，用户移动播放头后再次点击按钮将区间终点设置在播放头位置。应妥善处理用户在设置区间起点后放弃设置区间终点的情况、以及用户把终点设置在起点之前的情况（此时程序应该自动把起点和终点交换，使得区间的起点永远在前，终点永远在后）。用户按键盘上的快捷键（比如 1）时，应该触发与点击事件标记按钮相同的行为。
