# 数据源状态与历史查看 UI 原型设计

日期：2026-06-18

## 目标

为数据采集软件定义“实时数据查看与录制”和“历史数据查看与回放”的 UI 状态模型。初版只实现状态与交互原型，不读取真实 rosbag/video 历史文件，不实现历史数据解码、回放同步或后端持久化。

核心设计是：保留同一套主界面、相机预览和时间轴，将左侧 `采集记录` 面板升级为数据源选择器。面板顶部固定一个特殊的 `在线数据` 条目，下面是历史采集记录。用户通过选择 `在线数据` 或某条历史记录来决定当前查看的数据源。

## 当前背景

当前控制器已经有录制相关的 UI 状态雏形：

- `recording`：是否正在录制。
- `followingLiveEdge`：录制中是否跟随实时端。
- `playheadSeconds`：当前播放头时间。
- `liveEdgeSeconds`：实时端最新时间。

当前时间轴已支持录制中拖动播放头后脱离实时端，并提供 `回到实时` 按钮。这是未来“录制中回看”的基础。

当前 `采集记录` 面板只显示模拟历史 session 列表，尚未承担数据源选择职责。

## 数据源选择器

`采集记录` 面板在概念上改为 `数据源选择器`。面板标题改为 `数据`，因为它同时包含在线数据源和历史记录。

列表结构：

- 顶部固定 `在线数据` 条目。
- 下方显示历史采集记录。

`在线数据` 条目不是普通历史记录，不来自历史 session 数据。它是控制器层的特殊数据源入口，表示当前连接的 ROS topic 数据源。

`在线数据` 条目内容：

- 文本：`在线数据`
- 状态点：绿色，表示实时数据源可用。初版可固定为在线状态。
- 不显示第二行。该条目高度低于历史记录条目，避免把它误读成一条采集记录。

历史条目继续使用当前结构：

- 第一行显示 session 文件夹名或用户命名。
- 第二行显示时长。
- 右侧显示记录标签。

选中态：

- 当前数据源条目使用清晰的浅蓝选中背景。
- 可使用左侧蓝色竖条进一步强化选中态。
- `在线数据` 和历史记录共用同一种选中语言。
- 当前选中项决定相机预览、曲线区、事件轨道和状态栏显示语义。

## 状态模型

初版定义四个用户可感知状态：

1. `实时查看`
   - 当前数据源是 `在线数据`。
   - 未录制。
   - 播放头跟随实时端或显示最新可用实时数据。

2. `录制中`
   - 当前数据源是 `在线数据`。
   - 正在录制。
   - 播放头跟随实时端。

3. `录制中回看`
   - 当前数据源仍是 `在线数据`。
   - 正在录制。
   - 用户拖动时间轴或点击历史位置后，播放头脱离实时端。
   - 实时端继续前进，后台录制继续进行。

4. `历史查看`
   - 当前数据源是一条历史采集记录。
   - 不显示真实历史数据，只使用原型模拟数据。
   - 不允许直接开始录制。

内部可以拆成两个维度：

- `DataSourceMode`
  - `live`
  - `history`
- `TimelineFollowMode`
  - `followLiveEdge`
  - `manualReview`

用户可感知状态由这两个维度和 `recording` 共同决定。

## 状态转换

点击 `在线数据`：

- 从任何非录制历史查看状态回到 `实时查看`。
- 如果当前正在录制，则回到实时数据源，并进入 `录制中` 或 `录制中回看`，具体取决于是否跟随实时端。

点击历史记录：

- 未录制时进入 `历史查看`。
- 录制中初版不允许切换到历史记录，避免用户误以为后台录制的数据源也切换了。
- 若用户需要查看录制前历史，应先停止录制。

点击 `录制`：

- 仅在当前数据源为 `在线数据` 且未录制时可用。
- 进入 `录制中`。
- 播放头跳到实时端并开始跟随。

点击 `停止`：

- 从 `录制中` 或 `录制中回看` 停止录制。
- 当前数据源仍为 `在线数据`。
- 进入 `实时查看`。

录制中拖动时间轴或点击过去时间：

- 从 `录制中` 进入 `录制中回看`。
- 播放头停在用户选择的时间。
- 实时端继续前进。

点击 `回到实时`：

- 仅在 `录制中回看` 显示。
- 播放头跳到实时端。
- 进入 `录制中`。

历史查看中点击时间轴：

- 播放头移动到历史数据源的原型时间范围内。
- 不影响实时端。

## 状态栏

状态栏左侧显示当前主状态：

- `实时查看`
- `录制中`
- `录制中回看`
- `历史查看：<记录名称>`

录制按钮行为：

- `实时查看`：按钮显示 `录制`，可用。
- `录制中`：按钮显示 `停止`，可用。
- `录制中回看`：按钮显示 `停止`，可用。
- `历史查看`：按钮显示 `录制` 但禁用，或隐藏。初版推荐禁用并保持布局稳定。

状态栏不承担“退出历史查看”的职责。用户通过点击数据源选择器中的 `在线数据` 回到实时查看。

## 时间轴行为

时间轴仍是所有状态共享的主查看区域。

实时查看：

- 时间范围表示当前实时缓存或原型数据范围。
- 播放头显示当前实时位置。

录制中：

- 时间轴右边界随实时端增长。
- 播放头跟随实时端。

录制中回看：

- 时间轴右边界继续随实时端增长。
- 播放头停留在用户查看的历史位置。
- 时间轴信息面板显示 `回到实时`。

历史查看：

- 时间范围来自选中的历史记录原型时长。
- 时间轴不随实时端增长。
- 不显示 `回到实时`。

初版不需要实现播放/暂停、倍速播放或真实历史数据回放。历史查看中的播放头移动仍通过点击或拖动时间轴完成。

## 相机预览和曲线区

初版所有数据源都继续使用当前模拟数据。

实时数据源：

- 相机预览表示当前 ROS topic 的实时画面占位。
- 曲线区表示实时 topic 的数据流占位。

历史数据源：

- 相机预览和曲线区显示同一套原型数据，但状态栏和选中数据源明确说明当前处于历史查看。
- 后续接入真实历史数据时，再将数据源选择与历史文件读取绑定。

## 事件标记

事件标记轨道随当前数据源显示。

初版行为：

- 实时查看、录制中、录制中回看可以添加和编辑事件标记。
- 历史查看中可以保留事件标记 UI，但标记实例仍是原型内存态。
- 不把历史标记写入磁盘，也不从历史记录读取标记。

后续真实历史数据接入后，需要决定历史标记是否只读、可编辑并另存，或写回元数据文件。

## 不在范围内

- 读取真实 rosbag/video 历史文件。
- 历史数据的播放/暂停/倍速控制。
- 历史数据和实时数据之间的缓存管理。
- 后端录制状态机。
- 录制中切换到历史记录。
- 历史标记持久化。
- 历史记录重命名、删除或打开文件夹。
- 实时数据源断开检测。

## 测试

初版实现时应覆盖：

- `数据` 面板顶部存在固定 `在线数据` 条目。
- `在线数据` 条目没有第二行，并且高度低于历史记录条目。
- 点击 `在线数据` 会选中在线数据源。
- 点击历史记录会进入历史查看状态。
- 历史查看状态下录制按钮不可用。
- 录制中拖动时间轴会进入 `录制中回看` 并显示 `回到实时`。
- 点击 `回到实时` 会恢复 `录制中`。
- 状态栏根据状态显示 `实时查看`、`录制中`、`录制中回看`、`历史查看：<记录名称>`。
